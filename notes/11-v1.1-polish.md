## 5. Jurisdiction NOT NULL backfill

The half-finished item from 2026-05-26. Finish before it bites.

- [ ] Decide backfill default for legacy NULLs — likely a literal sentinel
      `"(unspecified)"` so users can re-edit, not auto-guess
- [ ] Migration `0017_compliance_item_jurisdiction_backfill.sql`:
      `UPDATE … SET jurisdiction='(unspecified)' WHERE jurisdiction IS NULL;`
      then `ALTER COLUMN jurisdiction SET NOT NULL`
- [ ] Verify against live: `SELECT COUNT(*) FROM compliance_item WHERE
      jurisdiction IS NULL;` returns 0 before adding the constraint
- [ ] Log the decision in `00-decisions.md`

## 6. Inspection-day "show pack" PDF

Strongest operator-delight feature still missing. Bundles all current,
non-expired docs into a single PDF an operator can hand to an inspector.

- [ ] Decide bundling strategy: server-rendered PDF (react-pdf / pdfkit)
      vs. zipping the originals. PDF is friendlier for inspectors.
- [ ] Endpoint: `/api/show-pack?truckId=…` returns a signed, time-limited
      URL; never bake docs into a public URL
- [ ] Cover sheet: account name, truck, generated-at, list of items + their
      expiration dates + statuses
- [ ] Exclude archived items and expired items by default; allow a query
      flag to include
- [ ] UI: button on the truck detail page + dashboard
- [ ] Verify: only the calling account's docs end up in the bundle
- [ ] Verify: extraction-pending docs are excluded or clearly labeled

## 9. Calendar (.ics) export

Sticky retention feature. Operators live in their phone calendar.

- [ ] Account-scoped, token-protected `.ics` feed:
      `/api/calendar/[accountToken]/feed.ics`
- [ ] Token is a long random per-account string stored on `account`
      (separate from session — calendar clients can't carry cookies)
- [ ] One VEVENT per non-archived item, DTSTART = expiration date, with
      ALARM at the item's first reminder offset
- [ ] Regenerate token button in Settings (kills the old URL)
- [ ] Verify: Google Calendar and Apple Calendar both parse it without
      warnings (`icalendar.org` validator)
